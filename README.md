# homebrew-tap

Homebrew formulae by CloudEngine Labs.

```sh
brew install cloudengine-labs/tap/artifact-cleaner   # provides `afc` and `artifact-cleaner`
brew install cloudengine-labs/tap/sbom-sentinel
```

| Formula | Platforms | Source |
|---|---|---|
| `artifact-cleaner` | macOS (arm64, Intel), Linux (x64, arm64) | https://github.com/chefgs/artifact-cleaner |
| `sbom-sentinel` | macOS (arm64, Intel) | binaries on this repo's Releases |

If Homebrew reports the tap as untrusted, run `brew trust cloudengine-labs/tap`.
